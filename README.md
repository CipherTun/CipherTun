Android networking, VPN, network intelligence and security tooling.

## Projects

### GlobalHostIntelligence

Android network intelligence toolkit for host discovery, subdomains, DNS, TLS, HTTP/HTTPS testing, certificates and web-surface analysis.

[GlobalHostIntelligence](https://github.com/CipherTun/GlobalHostIntelligence)

### CipherTun VPN

Android VPN application based on sing-box/libbox technology.

[CipherTun VPN](https://github.com/CipherTun/CipherTun-VPN-For-Android)

### V2-TUN

Xray-free tunnel library in Go for Android VPN apps. Supports VLESS, VMess (AEAD and legacy), Trojan, Shadowsocks and SSH over TCP, WebSocket, HTTPUpgrade, HTTP/2, gRPC, QUIC and XHTTP, with TLS fragmenting and uTLS fingerprints. Includes a gVisor-based TUN mode with full UDP relay, fake-IP DNS, SNI sniffing, domain/IP routing rules, Mux.Cool, BadVPN udpgw, share-link parsing and gomobile bindings.

[V2-TUN](https://github.com/CipherTun/V2-TUN)

### Pius

Security and reconnaissance tooling for Android/Termux environments.

[Pius](https://github.com/CipherTun/pius)
